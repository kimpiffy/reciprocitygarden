# Contributing

Welcome! You do **not** need to know how to code to contribute artwork or writing.

## The 5-minute version

1. Get the project running once (ask a developer, or follow "Run it" in the [README](README.md)).
2. Find your guide:
   - Drawing? → [docs/ILLUSTRATOR_GUIDE.md](docs/ILLUSTRATOR_GUIDE.md)
   - Writing? → [docs/WRITER_GUIDE.md](docs/WRITER_GUIDE.md)
   - Coding? → [docs/DEVELOPER_GUIDE.md](docs/DEVELOPER_GUIDE.md)
3. Make your change in **only** the files your guide mentions.
4. Look at it in the browser (`npm run dev`). Illustrators: add `?preview` to the address to see all your artwork at once.
5. Share it: send your files to the project lead, or open a pull request / upload through GitHub's **Add file → Upload files**.

## Ground rules

- One person per plant folder at a time, so work never collides.
- Keep the experience **gentle**: no timers, no failing, no pressure, no competition.
- Keep text short and readable. Visitors may be reading on a phone.
- Never delete a placeholder file unless you are replacing it with your own file of the same name.
- Before sharing code changes run `npm test` and `npm run build`.
